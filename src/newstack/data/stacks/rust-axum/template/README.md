# {{ title }}

{{ description }}

A small [axum](https://github.com/tokio-rs/axum) service, generated by
[newstack](https://github.com/DawnofGenX/newstack): typed routes, state shared through
`Arc<Mutex<Vec<Item>>>`, and integration tests that drive the router directly with
`tower::ServiceExt::oneshot` — no port, no sleep, no flakiness.

## Endpoints

| Method | Path      | Response                                        |
| ------ | --------- | ----------------------------------------------- |
| GET    | `/health` | `200` `{"status":"ok"}`                          |
| GET    | `/items`  | `200` `[{"id":1,"name":"widget"}]`               |
| POST   | `/items`  | `201` `{"id":1,"name":"widget"}`, `400` if bad  |

## Run

```sh
cargo run
```

The server binds `0.0.0.0:3000`. Set `PORT` to override it:

```sh
PORT=8080 cargo run
```

Shutdown is graceful: `Ctrl+C` (or `SIGTERM`) stops accepting connections, lets
in-flight requests finish, then exits.

## Test

```sh
cargo test
```

The tests build the router in-process and call it with `oneshot`, so they exercise the
same code the server runs without opening a socket.

## Build

```sh
cargo build --release
./target/release/{{ npm_name }}
```

## Try it

```sh
# health check
curl -s localhost:3000/health
# {"status":"ok"}

# list (empty to start)
curl -s localhost:3000/items
# []

# create
curl -s -X POST -H 'content-type: application/json' \
  -d '{"name":"widget"}' localhost:3000/items
# {"id":1,"name":"widget"}
```

## Layout

```
src/lib.rs    router, handlers, types, shared state
src/main.rs   listener, PORT handling, graceful shutdown
tests/api.rs  integration tests via tower::ServiceExt::oneshot
```
