# {{ npm_name }}

A small `wc`-style text counter written in PowerShell 7, generated by
[newstack](https://github.com/DawnofGenX/newstack).

The point of the layout is that the interesting logic never touches the process:
`lib/TextStat.ps1` counts bytes, `lib/Options.ps1` parses `argv`, and
`lib/Runner.ps1` decides what to print. Only `main.ps1` opens files, reads
standard input and exits, and it hands all of that to the runner as a hashtable
of scriptblocks, so the tests drive the real report without spawning a process.

## Requirements

PowerShell 7 (`pwsh`). Nothing else: no modules, no gallery downloads.

```
pwsh --version
```

## Use

```
./bin/{{ npm_name }}                         # count standard input
./bin/{{ npm_name }} sample.txt               # 2  3 17 sample.txt
./bin/{{ npm_name }} -w sample.txt            # 3 sample.txt
./bin/{{ npm_name }} -lw a.txt b.txt          # one row per file, then a total
printf 'alpha beta\ngamma\n' | ./bin/{{ npm_name }}   #       2       3      17
```

Flags: `-l/--lines`, `-w/--words`, `-c/--bytes`, `-h/--help`,
`-V/--version`; short flags cluster (`-lw`), `--` ends option parsing, `-` means
standard input, and a missing file is reported on standard error while the other
operands are still counted. Exit status is 0 for a normal run, 1 if any file
could not be read, 2 for a usage error.

## Output

Figures come in `wc` order, separated by single spaces, with the file name last.
Every column is right aligned to the width of the byte total, so a 17-byte file
prints ` 2  3 17`; a stream has no known size, so its columns use `wc`'s
seven-character field, and a single figure is never padded.

## Layout

```
main.ps1              process wiring: files, stdin, exit code
lib/TextStat.ps1      byte counting and row formatting
lib/Options.ps1       argv parsing into an options record
lib/Runner.ps1        the report: rows, widths, totals, exit status
tests/*.Tests.ps1     checks against the pure pieces with a fake I/O record
tests/Harness.ps1     three assertions and a summary
bin/{{ npm_name }}    wrapper that runs main.ps1 with a clean profile
```

## Test

```
pwsh -NoProfile -NonInteractive -File tests/Run-Tests.ps1
```

The harness prints `N passed, M failed.` and exits non-zero when anything fails.
The tests call `Invoke-TextStatRunner` with a hashtable of scriptblocks, so they
assert on the exact bytes written to standard output and standard error.
