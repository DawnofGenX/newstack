Hugo turns Markdown into HTML in milliseconds. This post exists so the build has
something to render, so the test suite has a page to assert on, and so you have a
working example of front matter to copy.

{{< note >}}
Edit this file at `content/posts/welcome.md`. The layout that renders it is
`layouts/page.html`, and the CSS is in `assets/css/main.css`.
{{< /note >}}

## What to change first

1. `hugo.toml` — the site title, base URL and description.
2. `content/` — your pages and posts.
3. `layouts/` — the HTML wrapped around them.
